# =========================================================
# fzf — Fuzzy Finder
# =========================================================
Ctrl+R no terminal — o que faz?	Pesquisa fuzzy no histórico de comandos (fzf)	fzf
Ctrl+T no terminal — o que faz?	Pesquisa fuzzy de ficheiros e insere o path	fzf
Alt+C (Option+C) no terminal — o que faz?	Pesquisa fuzzy de directórias e faz cd	fzf
Como forçar actualização da cache do Alt+C?	fzf-refresh	fzf
Onde está a cache do fzf Alt+C?	~/.cache/fzf-dirs-cache	fzf
De quanto em quanto tempo o fzf Alt+C regenera a cache?	24 horas (1440 minutos)	fzf
Que ferramenta o fzf usa para listar ficheiros?	fd (alternativa rápida ao find)	fzf

# =========================================================
# Zsh Vi Mode
# =========================================================
Como activar vi mode no zsh?	bindkey -v	zsh vi-mode
No vi mode, que cursor indica modo INSERT?	Barra fina (beam) — \e[5 q	zsh vi-mode
No vi mode, que cursor indica modo NORMAL?	Bloco (block) — \e[1 q	zsh vi-mode
Ctrl+A em vi insert mode — o que faz?	Vai para o início da linha	zsh vi-mode
Ctrl+E em vi insert mode — o que faz?	Vai para o fim da linha	zsh vi-mode
Ctrl+W em vi insert mode — o que faz?	Apaga a palavra anterior	zsh vi-mode
Como entrar no modo NORMAL no terminal?	Pressionar Escape	zsh vi-mode

# =========================================================
# Stow — Gestão de Symlinks
# =========================================================
O que faz o stow?	Cria symlinks de um directório para o nível acima	stow
Como aplicar config shell via stow?	cd ~/.dotfiles && stow shell	stow
Como remover symlinks do stow?	cd ~/.dotfiles && stow -D shell	stow
Que packages stow existem no dotfiles?	git, shell, ssh, ghostty	stow
Porque é que o stow falha com "existing target"?	O ficheiro original existe — mover/apagar primeiro	stow

# =========================================================
# Zsh — Opções e Histórico
# =========================================================
O que faz setopt AUTO_CD?	Permite mudar de directório sem escrever cd	zsh
O que faz setopt HIST_IGNORE_SPACE?	Comandos com espaço no início não ficam no histórico	zsh
Quanto histórico guarda o zsh (config actual)?	50000 comandos	zsh
O que faz HIST_IGNORE_ALL_DUPS?	Remove duplicados antigos quando um novo igual é adicionado	zsh
Onde está o ficheiro de histórico?	~/.zsh_history	zsh
